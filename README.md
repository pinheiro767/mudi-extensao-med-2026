# MUDI — Extensão Medicina 2026

Versão atualizada da oficina de Tecnologia e Divulgação Científica.

## Publicar no GitHub Pages
1. Substitua os arquivos do repositório pelos arquivos desta pasta.
2. Mantenha a pasta `assets` junto do `index.html`.
3. Faça commit/push.
4. O GitHub Pages atualizará a versão publicada.

## Destaques
- visual museográfico menos infantilizado;
- seis frentes: Anatomia, Segundo Cérebro, Anfiteatro, Plantas Medicinais, Química e Digital;
- exemplo de transformação científica com serotonina;
- roteiro de 120 minutos;
- construtor de divulgação, protótipo físico-digital e prompt de arte;
- ficha final imprimível/salvável em PDF;
- PWA offline após o primeiro carregamento.
